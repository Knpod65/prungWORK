# TA Hours Check

เว็บแอป (Google Apps Script + Google Sheets) ให้นักศึกษา TA ล็อกอินด้วย OTP ทางอีเมล @cmu.ac.th
ดูชื่อ / รหัส / ชั่วโมงรวม แล้ว **ยืนยัน** หรือ **รายงาน** (พร้อมคอมเมนต์) เจ้าหน้าที่เห็นสถานะรายคนและได้รับแจ้งเตือนเมื่อมีรายงาน

## ตารางในชีต (แคบ แยกตามหน้าที่)

| แท็บ | คอลัมน์ | หมายเหตุ |
|---|---|---|
| Config | key, value | ภาคเรียน (`TERM`), ชื่อระบบ, อายุ OTP, เปิด/ปิดอีเมลแจ้งเตือน ฯลฯ — แก้ได้ในชีต |
| Staff | email, name | ผู้ใช้ฝั่งเจ้าหน้าที่ (เพิ่มหลายคนได้) |
| Student | student_id, name, email | |
| Hours | term, student_id, round, hours | 1 แถว/คน/รอบ — เพิ่มรอบที่ 3 ได้โดยไม่ต้องเพิ่มคอลัมน์ |
| Response | response_id, term, student_id, status, hours_seen, detail, at | log แบบเพิ่มต่อท้ายอย่างเดียว (แถวล่าสุดของแต่ละคนคือสถานะปัจจุบัน) |
| Ack | response_id, by, at | เจ้าหน้าที่กด "รับทราบ" |

OTP และ session เก็บใน CacheService (หมดอายุเอง) ไม่เขียนลงชีต

## ติดตั้ง

```bash
npm i
npx clasp login
npx clasp push          # ใช้ .clasp.json ที่ชี้ไปยังสคริปต์ที่ระบุแล้ว
```

1. เปิดสคริปต์ใน editor → รัน `setup()` (อนุญาตสิทธิ์) → สร้างแท็บทั้งหมด + Config + Staff (`rungtiwa.p@cmu.ac.th`)
2. สร้างแท็บ `import_TA` แล้ววางข้อมูลจากชีต **"ส่งนักศึกษาตรวจสอบ"** (หัวตารางต้องมี ชื่อ-สกุล, รหัสนักศึกษา, จำนวนชั่วโมง รอบที่ N) → รัน `importHours()`
3. สร้างแท็บ `studentnow` วางข้อมูลทะเบียน (ต้องมีคอลัมน์ `ID`, `EMAIL`) → รัน `importRoster()` จากนั้นลบแท็บ `studentnow` (มีข้อมูลส่วนบุคคล) — ไฟล์ย่อเฉพาะ TA อยู่ที่ `seed/studentnow_ta.csv` (ไม่ถูก commit)
4. **ผู้ส่งอีเมล**: ระบบส่งในนาม `polsci.ecwp@gmail.com` (ค่า `MAIL_FROM` / `MAIL_REPLY_TO` ในแท็บ Config — เหมือน e-EXAM) ซึ่งต้องเป็นอีเมลที่เพิ่มไว้ใน Gmail ของเจ้าของสคริปต์ที่ Settings ▸ Accounts ▸ "Send mail as" และยืนยันแล้ว จากนั้นรัน `authorizeMailSend()` หนึ่งครั้ง (อนุญาตสิทธิ์ Gmail) แล้วเช็กว่าอีเมลทดสอบที่ได้แสดงผู้ส่งถูกต้อง — ถ้า alias ยังไม่พร้อม ระบบจะส่งจากบัญชีเจ้าของสคริปต์แทน (ไม่ล่ม) และบันทึกข้อผิดพลาดไว้ใน log; ปล่อย `MAIL_FROM` ว่างเพื่อใช้บัญชีเจ้าของเสมอ
5. Deploy ▸ New deployment ▸ Web app: Execute as **Me**, Who has access **Anyone** (ตัวตนยืนยันด้วย OTP) — หรือ `npm run deploy`

ภาคเรียนถัดไป: เปลี่ยน `TERM` ใน Config แล้ววางข้อมูลใหม่ + `importHours()` (ข้อมูลภาคเก่าไม่ถูกแตะ)

## ทดสอบ

```bash
npm test
```
ทดสอบ OTP / ยืนยัน / รายงาน / แดชบอร์ด / รับทราบ โดยจำลอง Sheets, Cache, Mail ในหน่วยความจำ

## คู่มือผู้ใช้

`docs/manual-v2/manual.pdf` คือคู่มือสำหรับนักศึกษา เจ้าหน้าที่ และผู้ดูแลระบบ (ภาพหน้าจอใช้ข้อมูลสมมติ) สร้างจากโค้ดจริงใน `src/` ทุกครั้ง:

```bash
npm run manual     # เรนเดอร์ภาพ + ตารางอธิบายจุดเลขต่างๆ แล้วพิมพ์เป็น PDF
```

ต้องมี Chrome หรือ chrome-headless-shell (ตั้ง `CHROME=/path/to/chrome` ถ้าหาไม่เจอ) เมื่อแก้หน้าตาหรือข้อความของระบบ ให้รันคำสั่งนี้ใหม่ จุดอธิบายแต่ละภาพอยู่ใน `docs/manual-v2/shots.mjs` (รายการเดียวสร้างทั้งกรอบเลขบนภาพและตารางใต้ภาพ) ส่วนเนื้อหาอยู่ใน `docs/manual-v2/build.mjs`

## หมายเหตุ
- ถ้าชั่วโมงถูกแก้หลังนักศึกษาตอบ (`hours_seen` ≠ ชั่วโมงรวมปัจจุบัน) ระบบแสดงป้าย "ชม.เปลี่ยน" และให้นักศึกษาตอบใหม่
- อีเมล OTP และอีเมลแจ้งเตือนรายงาน (ธีมเดียวกับหน้าเว็บ ส่งถึง `NOTIFY_TO` ในแท็บ Config ค่าตั้งต้น `rungtiwa.p@cmu.ac.th` คนเดียว เว้นว่างเพื่อส่งถึงทุกคนในแท็บ Staff) ส่งด้วย GmailApp ในนาม alias `MAIL_FROM` ผ่านบัญชีเจ้าของสคริปต์ (โควตาอีเมลต่อวันนับตามบัญชีนั้น)
